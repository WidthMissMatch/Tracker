Embedding the IMM console

The console runs inside a sandboxed <iframe>. It needs only allow-scripts. Everything below is a live embed on this page. 

<iframe
  src="https://widthmissmatch.github.io/Tracker/?seg=3"
  sandbox="allow-scripts"
  title="IMM radar tracker replay"
  loading="lazy"
  style="width:100%; height:640px; border:0"></iframe>

Options

ParameterEffect
seg=0…8Segment to open (default 3, F1 Monaco)
autoplay=0Open paused
speed=2Playback speed (0.1–20)
zoom=1.5Initial zoom (0.15–8)
follow=0Fixed camera instead of following the target
hud=0Hide the target box and footer
panels=0Stage and playback bar only
embed=1Force embedded behaviour (normally detected)

Sandbox notes

With allow-scripts alone the page is fully functional. It runs on an opaque origin, fetches its data cross-origin (GitHub Pages sends Access-Control-Allow-Origin: *) and keeps no state. Adding allow-same-origin enables its offline cache. Embedded copies never save settings and hide the GitHub link, because popups are usually blocked. Playback pauses while the frame is scrolled out of view.
